🚀 QUICK START

STEP 1: Run Locally (Choose ONE)

Python 3:
  cd /path/to/portfolio
  python -m http.server 8000
  # Visit: http://localhost:8000

Node.js:
  npx http-server

Or just double-click index.html in your file explorer.

STEP 2: Customize Your Information

Open index.html in any text editor and update:
  - Your name and title (line 50-51)
  - Your about section (line 123-135)
  - Your skills (line 150-180)
  - Your projects (line 200-350)
  - Your education (line 380-410)
  - Your achievements (line 440-480)
  - Your contact info (line 520-560)
  - All social media links

STEP 3: Test Everything

Mobile Test:
  - Open on your phone/tablet
  - Test all buttons and links
  - Test dark mode toggle
  - Test mobile menu

Desktop Test:
  - Test on Chrome, Firefox, Safari, Edge
  - Test responsive design (F12 → Device Mode)
  - Test all animations

Form Test:
  - Test form validation
  - Test success message
  - Test mobile form

STEP 4: Add Your Content

Profile Picture:
  - Save to assets/images/profile.jpg
  - Update HTML to use <img> instead of SVG

Project Images:
  - Save to assets/images/
  - Update project cards with real images

Documents:
  - Save CV to assets/documents/
  - Add links in HTML

STEP 5: Deploy to GitHub Pages

1. Create GitHub repository
2. Push your code: git push origin main
3. Go to Settings → Pages
4. Select "main" branch
5. Click Save
6. Visit: https://yourusername.github.io/portfolio

See DEPLOYMENT.md for detailed steps.
